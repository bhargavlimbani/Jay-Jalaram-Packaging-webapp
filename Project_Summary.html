Jay Jalaram Packaging is a real-world, production-grade web application built for a packaging manufacturing business. It digitizes the entire business workflow — from customer registration and product ordering, to invoice generation, payment collection, and admin analytics — replacing manual paper-based processes with a modern, secure, role-based digital platform.

Key Features
  • Role-based access control (Admin vs Customer) with JWT authentication
  • Customer self-registration with admin approval workflow
  • Product catalogue — Carton, Corrugated, Printed & Duplex boxes
  • Custom order placement with size/design specifications
  • Automated PDF invoice generation using PDFKit
  • Integrated Razorpay payment gateway for online payments
  • Email notifications via Nodemailer (OTP, password reset, order updates)
  • Forgot / Reset password with secure token-based email link
  • Admin dashboard with live order, revenue & material analytics
  • Raw material inventory tracking (Kraft Paper, Duplex Board, Gum)
  • Interactive sales charts (Chart.js) with revenue breakdown
  • Site-wide settings management from admin panel

AR
Architecture
  • MVC pattern on backend — controllers, models, routes fully separated
  • RESTful API design with 8 resource endpoint groups
  • JWT middleware for stateless, secure session management
  • Role middleware for admin-only route protection
  • React Context API for global auth state across all pages
  • Sequelize ORM for schema definition & auto-migrations
  • Environment-based config for DB, JWT, email & payment keys
  • Cloud MySQL on Aiven with TLS/SSL secured connection
